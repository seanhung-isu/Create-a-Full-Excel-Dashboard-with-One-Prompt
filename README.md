# AI 輔助資料視覺化動態儀表板

本專案示範如何將試算表或原始資料轉換為 JSON 格式，並利用 Claude 協助撰寫 HTML 程式碼，建立一個包含多樣化圖表的網頁版動態儀表板。

透過人工智慧與傳統試算表工具的整合，可以大幅降低資料整理、圖表設計與網頁儀表板製作的時間成本，讓原本需要數小時完成的資料視覺化流程，縮短至數分鐘內完成。

## 專案目標

本專案主要展示以下工作流程：

1. 將資料整理並轉換為 JSON 格式
2. 使用 Claude 依據資料內容產生 HTML 儀表板程式碼
3. 建立包含多種圖表的互動式網頁儀表板
4. 使用提示詞（Prompt）引導 AI 完成資料視覺化設計
5. 透過上傳儀表板截圖，讓 AI 反向產生設計提示詞

## 核心概念

本專案的核心在於「提示詞工程」與「資料格式標準化」。

透過設計清楚、具體的提示詞，可以讓 AI 更精準地理解資料結構、圖表需求、版面配置與視覺風格。再搭配 JSON 這類結構化資料格式，AI 能夠快速產生可執行的 HTML 程式碼，進一步完成網頁版動態儀表板。

## 主要功能

- 將試算表資料轉換為 JSON 格式
- 使用 Claude 產生 HTML、CSS 與 JavaScript 程式碼
- 製作網頁版動態儀表板
- 支援多樣化圖表呈現
- 可依據截圖產生相似風格的設計提示詞
- 提升資料分析與視覺化效率

## 使用情境

本專案適合應用於下列情境：

- 教學成果資料視覺化
- 問卷分析結果展示
- 專案績效儀表板
- 企業營運數據分析
- ESG 或永續指標視覺化
- 品質管理與製程數據監控
- 管理報表自動化展示
